# Hallow Provider Installer

This repository is a Home Assistant custom add-on repository.

## Structure

- Each add-on lives in its own subdirectory.
- Home Assistant reads the repo via repository.yaml.

## Add this repo in Home Assistant

1. Open Home Assistant.
2. Go to Settings -> Add-ons -> Add-on Store.
3. Open the menu and choose Repositories.
4. Add this URL:
   https://github.com/Maximillian-Detwiller/hallowproviderinstaller
5. Refresh the store.

## Included add-on

- hallow-provider-installer

This add-on installs the Hallow Music Assistant custom provider into the Music Assistant custom component directory.
